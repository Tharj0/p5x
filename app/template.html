    Il token resta solo in questo browser (localStorage di questo sito): non viene mai scritto nel repository del sito né inviato altrove che a api.github.com. Va inserito una volta su ogni dispositivo/browser. Ogni salvataggio diventa un commit nel repository dati (roster.json e wonder.json), quindi la cronologia di GitHub conserva tutte le versioni precedenti.

    Come creare il token (una volta sola)
    1. Su GitHub apri Settings › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token.
    2. Nome a piacere (es. p5x-tracker), scadenza a scelta, Resource owner: il tuo account.
    3. Repository access: Only select repositories → scegli solo il repository dati (es. p5x-dati).
    4. Permissions › Repository permissions › Contents: Read and write. Nient'altro (Metadata: Read-only si aggiunge da solo).
    5. Generate token, copia il codice (github_pat_…) e incollalo qui sopra, poi «Salva e collega». Ripeti l'incolla sugli altri dispositivi.
